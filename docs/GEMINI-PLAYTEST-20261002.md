# Gemini 3.8 Flash 独立试玩与地面修复

机主指出地面问题仍存在，并指定调用 Antigravity/Gemini 3.8 Flash 独立试玩。本机 CLI 为 `agy`；实际选择 `gemini-3.8-flash-high`。报告和截图保存在 `/home/baibai/outbox/pawborough-gemini-playtest-20261002/`，原始报告为 `BUGS.zh-CN.md`、机器可读数据为 `artifacts/BUGS.json`。测试在独立 Chrome、NVIDIA GB10 硬件 WebGL 中进行，没有改用户的浏览器进度或项目源码。

## 确认结果

Gemini 列出七项问题：老街北、九曲桥边、主入口、方浜四处坠入背景底板；单车轮/骑乘视觉、老街北顶板、取景标签。上桥受阻也包含在桥边问题中。坐标、截图和操作步骤以原始报告为准。报告中“缺少阶梯代理”“没有骨骼绑定”等原因属于试玩者推测；主控没有将其直接当成源码事实。

先前的修复只防止胶囊穿入已登记地面，并补了摊前铺面，没有阻止玩家把背景底板当成正常通道。独立试玩复现了 0.42m 的断层，`grounded=true` 仍可能表示站在不应进入的底板上。这推翻了以少数摊位测试代表全图安全的判断。

## 本轮修复范围

游玩模式区分 Y≈0 的实际通行面与 Y=-0.4 的背景底板。每次应用实际校正位移前，比较当前位置与下一步的可靠支撑；遇到无通行地面或无法正常退回的落差，原位重新计算位移并提示绕行。保留真实地面校核，不能用抬高显示模型或大平面冒充修复。骑车/停车/下车和存档恢复也排除底板；地下旧存档的落脚点不恢复，试吃进度保留。原查看器不启用这一游玩规则。

没有修改原 GLB 字节，没有把未验证的台阶、屋顶或单车美术问题标为通过。桥入口通行、单车显示、顶板和取景标签继续列入后续施工；本轮不宣称所有地图细节都已完成。
