**机器**：W2（Windows 11，NVIDIA GeForce RTX 3080 Laptop GPU，ANGLE Direct3D11，Chrome 154）。
**方法**：`?perf=1`（docs/PERF-W2.md 口径：首次加载计时 → 60 s 轨道 → 60 s 巡游步行，CruiseDriver 同 WalkController 输入链，路线 main→gold）。
场景由 S1 main `2e4dc3bf` 的 out-zone 经 SSH 隧道供给；W2 上 Chrome 以 headless=new、1920×1080 运行，经 CDP 远程驱动（主控执行，机主授权 2026-09-30）。原始数据：`docs/perf/W2-20260930-perf.json`。

## 读法与边界
- 1080p 下默认档步行约 **41 fps**（P95 帧 32.6 ms），关阴影约 **51 fps**；阴影 pass 占约一半三角与近半 draw calls，是最大的单项开销。
- headless 模式没有真实窗口合成与显示器同步，数字代表 GPU/JS 负载能力，可能与有头窗口略有差别；笔记本电源模式未核实（插电/性能模式会影响结果）。
- 加载时间是经局域网从 S1 取数据的时间，不是 W2 本地磁盘。

## v1.1 建议
- 阴影：减少阴影投射体（远处外围 L0 体块、细小构件不投影）或降低阴影贴图更新频率，目标默认档步行 ≥ 55 fps。
