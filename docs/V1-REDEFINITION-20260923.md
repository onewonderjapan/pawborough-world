# v1.0 改账：主体从「方浜中路街段」改为「豫园区域」（草案，待机主签字）

起草：主控（Claude），2026-09-23｜依据：Fable 审阅 `outbox/REVIEW-FABLE-20260923/REVIEW.md` 与执行计划 `outbox/pawborough-HANDOFF-OPUS-20260923.md` 1.2 节｜状态：**草案**，机主签字后在 `docs/OWNER_DECISION-v1-redefinition.json` 记录时间与原话，再同步 `PROJECT.json` 与 `README.md` 入口段。

## 为什么要改
- 2026-09-13 确认的 v1.0（`docs/ROADMAP.snapshot.md`）以方浜中路—玄扈台 91 m 街段为精修核心。
- 9/20 之后施工重心已经转到豫园区域全域候选（`scene-authoring/yuyuan-area`）：园、庙、商城、池带四区，按分区流式加载，运行时 15.4 MB。
- 机主 2026-09-23 的终点：**浏览器里可以进入、观看、互动**；视频用 AI 视频生成，3D 场景作参考 / 控制层，不换引擎。
- 路线图文本与 `index-v1.html` 入口仍指向街段，账与实际不符。

## 新口径
**范围**：豫园区域四区 = 豫园（garden）＋城隍庙（temple）＋豫园商城（bazaar）＋池带（pond）；外围（outer）保持 L0 体块作背景。方浜中路街段（仓库根 `world/`）作为**第二区域**，以后用同一套分区加载器并入，不在 v1.0 内重做。

**能力**
1. 分区流式加载，运行时 ≤ 20 MB（现 15.4 MB）。
2. 第一人称步行：碰撞、贴地、不穿墙、不落水，三条商业路线 R1/R2/R3 能走通（机器人巡游测试 + 机主在 W2 亲手走一遍）。
3. 固定机位取景导览（`tour.json`）。
4. 控制层导出：相机路径 + 深度 / 法线 / 分割序列，供 AI 视频使用。
5. 一条命令重建、一条命令验证；新环境按 `docs/MIGRATION-ASSETS.json` 能恢复全部资产。

**视觉底线**：园区精修 ≥ 20 栋（现 12）；商城 5 座命名大楼 + 底层店面精修；四区地面有铺装材质；湖心亭 / 九曲桥 / 大假山三个标志物经机主看图采用。

**不承诺**：外围 302 栋体块精修、历史测绘精度、角色、Unity。
