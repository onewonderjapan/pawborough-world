# v1.0 改账：主体从「方浜中路街段」改为「豫园区域」，并接上方浜中路（机主已签字 2026-09-23）

起草：主控（Claude），2026-09-23｜依据：Fable 审阅与执行计划 1.2 节｜状态：**机主已签字（附一条修订）**，原话与时间见 `docs/OWNER_DECISION-v1-redefinition.json`。

## 为什么要改
- 2026-09-13 确认的 v1.0（`docs/ROADMAP.snapshot.md`）以方浜中路—玄扈台 91 m 街段为精修核心。
- 9/20 之后施工重心已经转到豫园区域全域候选（`scene-authoring/yuyuan-area`）：园、庙、商城、池带四区，按分区流式加载，运行时 15.4 MB。
- 机主 2026-09-23 的终点：**浏览器里可以进入、观看、互动**；视频用 AI 视频生成，3D 场景作参考 / 控制层，不换引擎。
- 路线图文本与 `index-v1.html` 入口仍指向街段，账与实际不符。

## 新口径
**范围**：主体是豫园区域四区 = 豫园（garden）＋城隍庙（temple）＋豫园商城（bazaar）＋池带（pond）；外围（outer）保持 L0 体块作背景。
**机主修订（签字时加入）**：方浜中路那段已做好的街道要接过来，并且**从方浜中路走到城隍庙的那一段路也要建出来**。落实为第五分区 fangbang：
- 91 m 精修街段（地图 x 54–138，仓库根 `world/`，与全域布局同一张地图坐标，街段原点 = 地图 (53.5, −17.4)）；
- 街段西端到城隍庙山门（地图 (−74, 10)）约 128 m 的方浜中路连接段——根目录客户端 `world/fangbang-temple-v7`「方浜↔庙宇桥接世界」已有这段（主路线地图 x −89 至 286，可步行，但一直未经主控复验、未采用）；
- 以分区方式并入全域加载器，与庙区共用庙宇模块，不重复放置；
- 方浜中路其余路段（x −800 至 −114、138 至 362）仍按外围 L0 处理。

**能力**
1. 分区流式加载，运行时 ≤ 20 MB（现 15.4 MB）。
2. 第一人称步行：碰撞、贴地、不穿墙、不落水，三条商业路线 R1/R2/R3 能走通；**并能从方浜中路街段沿方浜中路走到城隍庙山门、穿过庙区进入商城与豫园**（机器人巡游测试 + 机主在 W2 亲手走一遍）。
3. 固定机位取景导览（`tour.json`）。
4. 控制层导出：相机路径 + 深度 / 法线 / 分割序列，供 AI 视频使用。
5. 一条命令重建、一条命令验证；新环境按 `docs/MIGRATION-ASSETS.json` 能恢复全部资产。

**视觉底线**：园区精修 ≥ 20 栋（现 12）；商城 5 座命名大楼 + 底层店面精修；四区地面有铺装材质；湖心亭 / 九曲桥 / 大假山三个标志物经机主看图采用。

**不承诺**：外围 302 栋体块精修、历史测绘精度、角色、Unity。
