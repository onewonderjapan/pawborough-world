已经明确的重点：

- P1：后视角遮住食品与进食动作；下车后的可见身体/车架重叠；夜间角色暗部结构丢失。
- P2：undefined/摊名提示、重复HUD、窄屏图鉴浏览区、空景/死黑门窗、摊台缺少种类差异。
- 待量化：骑车脚踏/脚撑细节。源代码已有骑乘和下车点计算，试玩者的“没有IK/没有安全点”不作为根因事实。
- 脚本缺陷已单独处理：Rapier新增摊车后必须刷新查询并清探针缓存；自动驾驶重入/安全出生点恢复保持诚实范围，不把它列游戏P0。
