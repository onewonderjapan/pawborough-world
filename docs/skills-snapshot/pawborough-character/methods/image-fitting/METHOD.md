# 从参考图制作可复建的猫

四主角现行正典由机主于 2026-09-11 采用：`/home/baibai/pet-content-studio/canon/current.json` 指向 Yaya/Gaga/Juju/Baibai 普通四足猫版本；Gaga 灰蓝眼及四只的配饰均已采用。旧刘海/双丸子身份只作历史档案，不再用于新角色。二维正典采用不等于新三维模型已通过。

目标是写出能重跑的 Blender 构造/变形脚本，让普通四足猫的轮廓、面部和柔软毛色接近参考。A 是幼猫，C 是成猫，B 是蓬松毛型；身份来自毛色与配饰。先交一只无配饰猫，脸和身体成立后再扩角色。

这套 Skill 提供局部可验证的方法，不是 Tripo 商业模型的内部算法。读取成品只能测量成品，不能从单个网格恢复生成权重、训练数据或原始建模操作。

## 按任务选择路线

| 路线 | 几何输入 | 可证明什么 |
|---|---|---|
| `template_fit` | 已认可且可用于本任务的猫底模 + 新参考图 | 有优质底模后，能否根据图片稳定扩展体型 |
| `independent_mesh` | 参考图 + 稀疏比例/关节说明；不得导入老师网格 | 本地构造能力；与参照同样渲染后看差距 |

直接改色、全局缩放、复制原 GLB 不能证明图片建模。`template_fit` 必须写清继承的网格和贴图；不能标成独立生成。任务要求两条路线时分别保存，不让独立路线的脚本读取老师模型、老师贴图或完整顶点数组。

先读 [构造方法](references/construction.md)。本机素材、已测失败和实际命令见 [当前试验](references/current-trial.md)，已有实作结论见 [试验结果](references/trial-results.md)。这是试验入口，不是继续花积分或改正典的授权。

**当前能力边界：**底模拟合经 GLM 代码和主控修正后有可用进展；独立网格试验已经真实渲染，但没有达到参考质量。不要默认“连续截面”文字说明就能产出自然猫，也不要重新跑失败代码当生产建模。

当前 A 底模的可重跑例子是 [template_fit.py](scripts/template_fit.py) 与 [测量参数](assets/a-to-c-profile.json)。该脚本检查输入哈希并要求新的输出位置；适配其他猫需重新测量。可以让 GLM 修改一组明确参数，再由主控运行和看图，比要求它在一次长代理循环中完成所有工序更可检查。

## 执行顺序

1. **看图、定坐标。** 记录各视图图片尺寸、耳尖/颅顶/下巴/眼心/鼻/肩胯/四脚的像素坐标。统一脚底和耳顶后比较比例。图生四视图不是精密摄影测量；冲突记入 `measurements.json`，正面优先脸宽和眼距，侧面优先躯干和腿长。
2. **先用中性站姿修轮廓。** 正面、侧面、3/4 同看。保留颅顶—眉弓—眼眶—颊—口鼻的连续变化，以及胸廓—肩—前腿、骨盆—大腿—跗部的过渡。参见构造方法中的截面、区域变形和眼眶写法。
3. **再做颜色和表面。** 灰模先检查下巴突起、外贴眼球、球形肩膀、折断后腿。随后基础色/无 normal/PBR 分开看，毛流主要由贴图和弱表面变化承担。细密刻痕不能替代毛感。
4. **导出实际 GLB 再渲染。** 使用本 Skill 的 [render_review.py](scripts/render_review.py)，保证相同尺度、灯光和视角。生成 `front/side/back/three/clay-three.png`，不要用参考图冒充渲染。离线材质不能导出时明确写降级内容。
5. **仅在轮廓合格后绑定。** 需要动画时读取 `pawborough-cat-modeling`，重新拟合完整四肢链、裁剪四权重、按实际足底校准。改了腿长/骨架，旧动作不能未经检查就继续交付为已验证步行。

## GLM 的交付方式

机主要求「写计划/启动指令，我自己给 GLM」时，只准备手动交接包，不运行试跑、派单、创建心跳或恢复旧自动任务。GLM 收到机主指令后在其当前会话执行；包内历史定时配置不是启动授权。

GLM-5.3-Flash 的原生多图输入已经实测。跨夜制作必须读 [视觉迭代工序](references/vision-night.md)：把参考图和实际导出模型的渲染作为原生 image 内容块送入同一个模型，不能用只读文本接口替代，也不要把它写出的“正在调用 analyze_image”文字当工具成功。

代码与关键参数分离；参数记录来源：图片实测、老师稀疏统计、推断、手工修正。每次修订保留脚本和实际图，说明本次针对哪个可见问题。先完成一版低样本多视图，再修最影响观感的两处；不要堆出十个只有名字不同的候选。

每条路线交付可重跑命令、`model.blend`、`model.glb`、四视图+灰模、实际面数/材质/UV/动画统计、来源说明和剩余问题。技术通过与美术达到目标分别报告。若 GLM 没有可用视觉工具，说明不能自行看图，由主控读实际渲染反馈；不要凭文件存在打审美高分。

第一轮静态形体试验可以没有步行动画。失败也交真实模型、脚本和图，保留下一轮能定位的差距。最终是否采用由机主决定。
