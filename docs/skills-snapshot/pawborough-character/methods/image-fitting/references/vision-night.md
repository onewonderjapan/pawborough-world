1. 输入机主采用的四猫板、该猫四视图，以及上一版真实渲染（如果有）。用名字和列号明确哪只猫是目标。旧发型参考不可混回当前输入。
2. GLM 输出完整可重跑 Blender Python。生产路线从已认可 A 中性底模副本改形、改毛色/眼色并做配饰；独立研究路线不提供老师网格/纹理。两者来源标签不同。
3. 构造脚本用实际绝对输入/输出路径，旧 /inputs 与 /work 只有经过映射才成立。可复用本包 Landlock + seccomp 隔离执行器，先将脚本放到本版工作目录；CPU 六线程，一次一个 Blender。输出真实 Blend/GLB、参数或构造说明。

6. 从较好的版本继续修改，保留失败版本。GLM 的选优是建议；不要覆盖正典或自动采用 3D。到次数上限或截止时间，带着最好与失败样本交付。

## 具体修形提醒

- 整个头面和眼鼻应共享稳定缩放，过渡放颈根；不能把头中心距离当整个脸的缩放权重，导致眼鼻缩进去、颊和耳不动。
- 增加腿长应带动肩胯抬高，脚底锚定；不能在肩部把高度增量衰减回零。
- 收腹选区应排除腿爪。脚掌的接触面和角度都要看，最低一个顶点为零不代表自然着地。
- 眼要露出且被眼睑包住，既不能完全埋没，也不能外贴完整蓝球；看正面和侧面再继续。
- 毛色变化要保护眼鼻胡须、保留毛流明暗，不能全身统一 tint 把眼也涂成毛色。GLB 不支持的程序材质应烘焙或明确降级。
- 配饰根据真实表面贴合，可用 BVH 沿颈部截面求表面位置；以当前模型米制尺度重新确定，不复制旧 1 米模型的坐标。
