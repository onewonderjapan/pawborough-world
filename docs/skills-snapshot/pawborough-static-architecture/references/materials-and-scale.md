## UV计量

UV0可超出0–1以重复贴图。记录整张纹理覆盖的实际宽/高米数，例如一张含4块长砖、16行砖的贴图，若制作采用砖长约0.25m/行高约0.075m，可试tile约1.0×1.2m；这是制作校准，不是测绘事实。按实际图中砖数校准，而非把旧工程数值当真理。

面向+Z的GLB墙面可用 u=(x+建筑公共偏移)/tileWidth、v=y/tileHeight；转到其他墙面时使用该立面的切线/高度。凹口侧墙和窄构件按物理尺寸投影，不能随主面UV拉成彩带。若将UV按米预缩放，纹理Mapping不要再重复缩放。木纹横梁和立柱分别用长轴方向确定纹理方向。

即便是静态模型，重复砖UV也不能作为唯一lightmap UV。以后烘焙光照再生成独立非重叠UV；当前未烘焙时如实标记。

## 建模与画面优先级

平直墙面、成对窗框、门套厚薄关系、檐口连续性优先。倒角宜小，过大的圆边会把漆木/砖石变成塑料积木。倾向用少量不同粗糙度响应区分石、漆、砖，不把全物体统一加噪点。门/窗是区域视觉锚点，可比普通墙面多分面；屋瓦仅在轮廓需要的位置布几何。

当材质无法从程序节点完整导出GLB，可在低模单平面上烘焙重复材质图；这不需要高模。原素材缩放到1K/2K应保留颜色空间与对应贴图一致性。一般先复用许可PBR素材，避免为每栋重新生成独占大贴图。
