# 老城隍庙、豫园及周边老城厢

## 当前方向

机主已明确目标区域，并反馈旧样板的材质方向基本接近，颜色和形状仍不像。旧5.6m灰砖住宅仅为直接低模/材质/加载技术样例，不再作为本区域造型母版。用户手机截图为泛石库门门头偏好，尚未定位，不能声称照片就在城隍庙。

机主已确认时代主体为1990—2000年，并明确要求复刻猫猫墙。猫墙按2023艺术季公开实景作为指定特色加入，不以年代不同拒做，也不称其为90年代原有。建筑、店招与街道生活层优先核对90年代资料。当前地图范围沿方浜中路延伸至东门路/黄浦江，并向城隍庙与豫园展开。

## 先分建筑类型再选择构件

- 城隍庙庙宇：以具体山门/殿宇正侧面为依据确定屋面曲线、檐口、柱网、台基和院落关系；不能把普通住宅加一块匾就当庙。
- 豫园园林：屋顶、墙洞、廊和水边空间服务园林关系，不能套用整排临街店屋。
- 豫园商城/沿街店面：依据具体街段确定多层檐线、木格窗、开敞店面、牌匾和商业尺度。某些夜景资料含节庆装饰，不能自动加入所有场景。
- 附近普通店屋/里巷：核对实际街段的房屋高度变化、前店后宅/入口、砖与灰泥、门窗和生活设施；有石库门才选对应门头，不能把外圈全部做成庙宇或全部做成同一灰盒。

以上是建模分类，不是已核实每一栋的样式。每个施工对象仍需对应可定位照片。

## 色彩与形状的检验顺序

先从指定街段的日景选主色关系，不用商城夜间灯光反推材质底色。分清瓦屋面、漆木、墙面、砖/石和招牌。用户所给截图可观察到深门洞、红灰砖对比、厚石门套及弧形/拱券/雕饰，但这些只说明偏好，不给地理或尺寸结论。

遮掉纹理时，檐线、拱券/门套、窗格分布、开间与高度仍应接近选定参考。重要曲线用少量连贯截面做真实轮廓，不能因低模把飞檐全拉直、拱门改方门。材料微细节保持原已验证流程；节省面数优先省看不清的小刻纹。

先验证一个有具体参照的沿街门面与相邻转角，暂不扩成整区施工。保留照片位置/日期、正侧面、未见背面的推定、设计尺寸和低模预算。机主接受形体/色彩后再决定复用的模块族。
