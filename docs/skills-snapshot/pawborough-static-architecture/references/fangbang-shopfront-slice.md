# 方浜店屋：已验证的小段做法

适用于老城隍庙周边商业店屋的小批施工。当前基准是“檐下三间”，不是庙宇、园林或全上海住宅的通用模板。

## 基准及证据

`/home/baibai/outbox/pawborough-fangbang-detail-slice-20260912`：先看workspace/public/shots/street-pbr.jpg、street-clay.jpg与cat-pbr.jpg，再读building/build.py及BUILD_NOTES.md。40,084 tris、7,684,112 bytes，44个节点、20材质、18纹理，Validator 0错误0警告（53条信息）。结果来自实际导出、重导入和浏览器画面；未验证完整游戏通行、Unity或全城性能。

机主反馈“我现在这么看效果是不错的”。主控将其作为下一轮有限试制基准；建筑年代、具体店址和全区复制仍不是已验证结论。时代主体1990—2000，猫墙为指定保留的2023特色。

## 复用什么

- 连续曲线屋面与檐口轮廓；瓦口只在边缘布少量几何，瓦沟用共享法线。普通店屋不自动升级成庙宇重檐。
- 分墙留洞、内退窗扇、入口浅进深陈列。楼板收进墙体内，避免外缘与外墙共面。
- 冻结灰瓦、深红棕木、浅灰墙、少量金色字面的主关系，变化开间、檐高、窗型和商业陈列。
- 原材质保留在textures；木色由prepare_pbr.py在Blender里烘成真实图，make_maps.py负责瓦纹与本地字体排字。来源图片不直接充当完整店面纹理。
- 按栋/部件与共享材质组织，支持替换一栋而不重建整城。

## 这轮真正踩过的坑

1. UV投影必须按面朝向：正面XY投影会把侧山墙压成一条线。以实际退化UV/切线的面定位问题，不靠删除法线图过校验。
2. 导出前明确三角化。极细长檐板的小倒角曾出现零切线；该样例取消宽厚比大于55的微倒角后修复。55是这份样例的经验值，不是通用建模阈值。
3. 招牌字面比例、檐托遮挡必须正面看图。支架放两端或牌匾上方，不横穿商号字。
4. 单张猫画保持比例，以UV把背景延伸到整面墙并用clamp-to-edge消除贴纸矩形边。仅适用于当前这种可延伸背景的图，不机械推广到所有墙绘。
5. 不透明纹理按最终可见质量选择编码；该样例改用JPEG使大PNG开销下降。带alpha的毛发/剪影不能照搬此选择。

## 下一阶段的美术取舍

机主已明确“新不是问题”，并指出连续感和房屋组合会随扩大施工范围改善。保留现有清爽、较新的质感；不把做旧、脏污或单体样品缺少整街密度设为验收条件。单体阶段验证形体、材质、店型区别与可拼接接口；街区阶段再验证两侧界面、转角、巷口、街宽和连续檐线。通过不同开间/屋高/窗型及业态陈列建立变化，道具保持正确的支撑与尺度。

比较图需要固定相机、光照和模型版本。同布局简化体块只能帮助拆解贡献，不能冒充真实旧版本，也不能据此给出客观提升百分比。新批次独立目录交付；用户未要求时不增加定时任务、不覆盖已认可的小样。
