# 已施工的街屋示例

工作样例：`/home/baibai/outbox/pawborough-static-building-skill-proof-20260912/building/`。

读取 `build.py` 可了解：按开口分墙、逐面loop UV、连接网格后倒角、门套退台、上下窗扇、沿X屋脊和闭合侧山墙、按共享材质合并、原生glTF坐标检查。源文件以其所在目录为输出目录；想派生新建筑时先复制到新的outbox目录，再修改设计参数，避免覆盖原样板。

尺寸 W/D/EAVE/RIDGE 与原点是该样例的设计值，不是上海建筑通用尺寸；不同参考应调整。外观也不是所有建筑的固定模板：主控需依据门是否开放、窗的构造、屋脊方向、可达背面及参考材质选择组合。

调色示例：黑漆木门可以保留木纹法线/粗糙度，底色使用深色常量；原木Color图不连到Principled时，不计为GLB的实际使用图。检查真正导出的图像/材质，不能只数脚本载入了多少张图。

该示例已进行的验证及限制以同一试验包 `RESULT.json` 和Skill的 `verification.md` 为准；构件基础与单样例成功不等于整座城市性能已验证。
