# REVIEW · 方浜市声试玩首页与便携包（world-playable-night 20260920）

执行：ZCode GLM-5.3-Flash；分支 `work/world-playable-night-20260920`；基线 `68f10ea`（上游 lane-b-polish 补修终态）。机主采用与否（ownerAdopted）仍待您决定。

## 怎么看（30秒）

1. 启动便携包（见下）或在工作区 `npm run dev` 后打开 `http://127.0.0.1:5410/world-preview.html`。
2. 首页第一屏：标题「方浜市声」、一句导语、右侧是真实街景宽幅图（来自游戏实景）。四个出发点（主街 / A弄 / B弄 / 庙前）点一下即可换图与说明；导览图按实测路线绘制，可点击、可用键盘 Tab+回车选择。
3. 「开始探索」进入游戏页并落到所选出发点（显式定位，不计入行走证据）；「先看场景」直接看下方图库。

## 建议的手动试玩顺序（约10分钟）

1. **主街**：「开始探索」→ 点击画面锁鼠标 → 沿主街向西行走（W），路过两处弄口，直到庙前广场。
2. **A弄往返**：回首页选 A弄 → 进弄走到尽端壁龛 → 原路退回主街（S）。
3. **B弄往返**：同样方式进 B弄，注意弄身渐宽的「口袋」和尽端回望主街的视角。
4. **庙前**：回首页选 庙前 → 正望「保障海隅」门额 → 沿庙轴线走进前院，到大殿台阶脚（台阶按设计不可攀爬）。
5. 期间可用：P 暂停 · V 取景/行走切换（保持位置）· Esc 暂停 · 空格小跳 · 页头「场景总览」回首页。

无自动完成勾选；以上是人工路线建议。游戏页内的「路线巡游检查」是自动过程，已在验收中运行，不冒充人工试玩。

## 入口衔接与异常状态

- 首页只链接 `fangbang.html?ds=fangbang-temple-v7&entry=<id>`，entry 仅接受四个已验证锚点；非法值回退主街并给出说明，缺省值保持旧页行为不变。
- 游戏页新增「场景总览」返回入口（相对路径）；旧 `fangbang.html` 直接打开不受影响。
- WebGL 不可用时：游戏页显示可操作的面板（说明 + 折叠技术明细 + 重试 + 返回场景总览），不再无限「正在初始化」；首页与图库无 3D，仍可浏览。
- 资源失败会指明资源类型与路径；重试是用户点击刷新（单次动作），无后台无限重试。

## 便携包

- 构建：`node scripts/build_playable_package.mjs` → `dist-world-playable/`（构建器拒绝覆盖已存在目录，不删除任何文件）。
- 启动：`python3 start-world-playable.py [端口]`（127.0.0.1，默认5411，端口占用会明确报错不杀进程）；无 python3 时 `node start-world-playable.mjs`。
- 包内：编译首页/游戏页、v7 依赖闭包、可选 skins/props、图库、README、`package-manifest.json`（逐文件字节+SHA-256，不含自身哈希）。不含 .blend 源工程与历史视频。
- 交付 ZIP 及其外部 SHA-256 收据见 `artifacts/world-playable/delivery/`；restore 验证目录 `restore-world-playable/` 保留在磁盘。
