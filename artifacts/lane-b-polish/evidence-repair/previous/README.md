# 撤回说明 — 原路线性能结论（2026-09-20 主控 B7-R1/B7-R2）

本目录是补修前原始交付文件的字节快照，仅作留档，不删不改。

## 撤回的结论

原 `runtime-baseline.json`（快照于本目录）中的“≥90 秒主街+A/B 弄环路行走 P50/P95”
**不作为路线完成与性能证明**，理由（主控 2026-09-20 复核实证，REVIEW.md B7-R1）：

1. 运行脚本 loop 航点为 `[x,z]` 二维目标，但转向计算读了 `tgt[2]`（undefined），
   `want`/`d` 变 NaN，转向分支永不触发——玩家实际沿出生朝向直线行走，
   并未按声明完成“主街+A/B 往返环路”负载；也没有到达/卡住断言。
2. 帧间隔只保留了排序后最快 60 个样本，无法从原始样本复算分布；
   `firstValidFrameAfterReadyMs` 字段实际存的是 navigation timeOrigin 相对值，
   字段名与口径不符，且“首有效帧”仅凭 cpuSubmitMs>0 判定，未做真实渲染检查。

原数据不是伪造——它们是该脚本在该负载下的真实采样；问题在于该负载不等于
声明的约定负载。几何/物理/预算等其他结论不在本次撤回范围（主控已复验通过）。

原 `delivery-manifest.json`（快照于本目录）60 条中 59 条与实文件一致，
仅清单自包含条目（第 245 行）保存的是写入前旧哈希，结构上无法自洽（B7-R2）。
新清单由 `tools/lane_b_delivery_manifest.mjs` 生成并排除自身，摘要写入独立收据
`../delivery-receipt.json`（不在清单内）。
