# U05 美术试验段单体小样与材质复用

本目录为工单 U05（中心—食摊—方浜交界的整体美术试验段）的单体小样、配方规范与预算计量。

## 目标与原则
1. **原世界 GLB 只读**：不修改或重建现有三维建筑模型；采用运行时共享程序化材质和非破坏性叠加。
2. **三处焦点**：
   - 中心广场 (`center`: `[-157.75, -22.25]`)
   - 肠粉小吃摊 (`changfen`: `[-154.811, -25.189]`)
   - 方浜老街接缝 (`fangbang_seam`: `[-96.8, 20.75]`)
3. **针对三大视觉缺陷**：
   - **死黑窗** (`recessed-old-glass`)：改换为有深度的背板、微弱环境反射与柔和透光，消除死黑空洞感。
   - **闭店门板** (`deep-door-lacquer`)：改换为暖色调旧木漆（古法朱漆/栗壳漆木纹），明确“暂停营业/暂不开放”，不伪造入口。
   - **铺地边与接缝泛灰** (`worn-stone` / `paving-fine-cobble`)：引入暖灰水刷石踢脚线（`curb-trim`）与暖调石皮，消除冷灰生硬边界。
4. **净空与通行**：
   - 道具贴近墙边和路缘，净空距离距人行通道中心线 > 1.5m。
   - 绝对不封堵门洞、月洞门与九曲桥入口。
   - 物理碰撞严格保持只读，不新增任何阻挡玩家与单车的刚体。
